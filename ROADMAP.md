# Roadmap

Version 1 scope is fixed in [`docs/PRODUCT_SPEC.md`](docs/PRODUCT_SPEC.md) §17. Ideas below are **not** part of Version 1 and should not be silently implemented — they need a scope discussion and maintainer sign-off first.

## Under consideration for future versions

- Linux support (production-quality, not just "runs on Linux")
- Additional AI providers (local models, more cloud providers) contributed by the community
- Fully automatic AI actions for high-confidence, previously-approved patterns (opt-in, still revocable)
- A CLI interface, reusing the same shared core as the desktop UI
- Rule-based (non-AI) semantic subfolder suggestions, e.g. "Invoices" heuristics without content extraction
- Scheduled/batch review sessions instead of only real-time review

## Explicitly out of scope (not just "later")

- Mobile applications
- Cloud file storage / sync
- User accounts
- Team synchronization
- Remote file management
- Automatic deletion of files
- Mandatory subscriptions
